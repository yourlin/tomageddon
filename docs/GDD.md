# 番茄酱 Tomageddon · 游戏设计文档（GDD）

**中文** · [English](en/GDD.md)

## 1. 概述

| 项目 | 内容 |
| --- | --- |
| 类型 | 俯视角 2D 割草 / 竞技场生存 Roguelite |
| 平台 | 浏览器（PC + 移动端横屏），Phaser 3（WebGL）+ TypeScript + Vite |

| 世界观 | 番茄酱小镇被“腐烂”侵蚀。番茄妹与蔬果伙伴从厨房一路打到番茄酱工厂，击败腐烂之源。 |

## 2. 核心循环

```
选择角色 + 章节（每局随机抽取 2 名精英与 1 名 Boss）
  └─ 战斗波次（20~60 秒，Boss 波 90 秒，超时 Boss 狂暴）
       ├─ 走位躲避弹幕 / 预警圈 / 激光 / 冲锋
       ├─ 武器自动索敌攻击；手动释放角色技能
       ├─ Buff/Debuff 互相博弈（中毒、冰冻、诅咒 vs 护盾、怒气、急速……）
       └─ 击杀掉落番茄籽（经验+货币）、果实（回血）、宝箱（道具）
  └─ 结算：收获、利息 → 升级选属性 → 开宝箱 → 商店（买卖、合成、刷新、锁定）
  └─ 第 5/10 波精英，第 7 波起随机出现“词缀精英小怪”，第 15 波 Boss
通关解锁下一章与新角色；累计击杀 / 通关次数也会解锁角色
```

## 4. 属性系统（21 项）

最大生命、生命再生、吸血、伤害%、近战/远程/元素伤害、攻速、暴击、射程、护甲、闪避、移速、幸运、收获、拾取范围、经验获取、技能冷却缩减、技能伤害、技能范围、技能持续。

- 护甲减伤 `15/(15+护甲)`；攻速冷却 `基础/(1+AS%)`；闪避上限 60%（南瓜幽灵 75%）
- 武器伤害 `(基础 + Σ属性×系数) × (1+伤害%) × 类别倍率`，暴击 × 武器暴击倍率 ×（1+暴击伤害%）
- Buff/Debuff 会实时叠加到属性上（例如“急速”+移速+攻速，“致盲”-30% 射程）

## 5. Buff / Debuff 系统（28 种）

玩家与敌人共用 `StatusSet`：叠层、计时、持续伤害、属性汇总、护盾吸收、控制抗性。

| 减益（16） | 增益（12） |
| --- | --- |
| 灼烧、中毒、流血、腐烂（持续伤害）| 急速、怒气、护盾、再生 |
| 减速、黏液、冰冻、眩晕（控制）| 坚韧、无敌、荆棘、专注 |
| 虚弱、易伤、破甲、诅咒（削弱）| 屏障、暴怒、好运、嗜血 |
| 致盲、混乱、沉默、标记（特殊）| |

**来源**
- 玩家 → 敌人：武器效果（灼烧/减速/眩晕）、角色被动、道具“命中时施加”、技能、光环道具
- 玩家自身：技能自我增益、道具（击杀/受伤/闪避/每波开始/周期触发）
- 敌人 → 玩家：小怪攻击附带（毒蜂中毒、老鼠流血、冰蚊冰冻、诅咒娃娃诅咒…）、Boss 招式附带、精英词缀（冰霜/剧毒/诅咒）
- 敌人自身：Boss `buff` 招式（屏障、再生、急速）、二阶段暴怒、词缀（护盾、狂暴、统帅光环）
- Boss 对控制类减益有 75% 抗性（精英 50%），避免被控死

HUD 左上显示玩家所有状态图标、层数与剩余时间圈；敌人身体会按状态着色（冰冻蓝、灼烧橙、中毒绿、诅咒紫）。

**大招数值规则**（与角色当前属性挂钩）
- 伤害 = 当前所有武器平均单次伤害 × 招式系数 × (1 + 技能伤害%)
- 范围 = 基础半径 × (1 + 射程/600，限制 0.8~1.4) × (1 + 技能范围%)
- 持续时间（领域/增益/无敌/分身/施加的状态）× (1 + 技能持续%)
- 冷却 × (1 − 技能冷却缩减%，最多 −70%)；每波开局需等待 40% CD 才能首次释放
- **CD 按威力自动计算**（`src/data/skills.ts`）：
  `CD = 8 + 0.9×伤害分 + 控制分 + 增益分`，限制 12~45 秒
  - 伤害分 = 系数 × 预估命中数（范围越大、弹数越多，命中数越高）
  - 控制分 = 状态强度（眩晕/冰冻 4/秒、易伤 0.6/秒、减速 0.4/层·秒……）× 命中数 × 0.16
  - 增益分 = 自身状态强度 + 无敌时长×3 + 回复比例×30
  - 结果：环形弹幕约 12 秒，突进 15~19 秒，周身爆发 27~36 秒，群体减益 27~37 秒，核弹类 35 秒左右

**技能强化**：新增 3 项属性「技能伤害 / 技能范围 / 技能持续」，与「技能冷却缩减」一起，由 2 个道具系列（技能秘籍、技能法器，共 20 件）和升级选项提供。

## 7. 道具（562 件）

- **42 件手工设计**（经典道具，含复活、额外武器栏、泡泡护盾等关键道具）
- **520 件系列道具**：52 个主题系列 × 10 件（含 2 个技能强化系列）（普通 4 / 稀有 3 / 史诗 2 / 传说 1），如番茄制品、香料、刀具、锅具、冰品、雷电、毒物、草药、茶饮、咖啡、甜点、宝石、戒指、护身符、忍具、海盗、实验、星辰……
- **强度预算制**（`src/data/itemGen.ts`）：每稀有度固定预算 [10, 22, 40, 75]，每点属性有单价（由手工道具校准，如 1 最大生命 = 3、1% 攻速 = 2、1 护甲 = 4.5）。
  - 稀有以上带系列专属特效（占预算 35~45%），特效强度按预算换算（如“命中 x% 中毒”）
  - 史诗/传说部分带代价属性，换取 +27% 预算
  - 保证同稀有度道具强度一致、价格合理，避免出现“必买”或“垃圾”道具
- 图标由 30 种造型 × 系列配色程序绘制，按需生成

## 8. 敌人

### 8.1 小怪（25 种，9 种 AI 行为）

追击、游荡、蓄力冲撞、保持距离射击、自爆、分裂、治疗同伴、召唤、留下黏液。多数小怪攻击附带减益。每章前几波以霉菌团/果蝇为主，特色怪从第 2~4 波加入。

### 8.2 精英（30）与 Boss（15）

- 每章 6 名精英 + 3 名 Boss，每局随机抽取 → 重玩性
- 11 种招式：`ring` 环形弹、`spiral` 螺旋、`aimed` 扇形瞄准、`scatter` 乱射、`charge` 预警冲锋、`slam` 预警砸地、`hazard` 持续危险区、`laser` 预警激光、`teleport` 瞬移、`summon` 召唤、`buff` 强化同伴
- 招式可附带减益（打中玩家时生效）或增益（给自己和周围怪物）
- Boss 血量 ≤ 50% 进入第二阶段（加速、冷却缩短、新增招式、部分获得暴怒/屏障）；Boss 波 90 秒后狂暴

### 8.3 精英词缀（12）

迅捷、坚甲、狂暴、再生、冰霜、剧毒、诅咒、护盾、爆裂、吸血、荆棘、统帅。
精英：第 10 波起 +1 个随机词缀，第 3 章起 +1，第 5 章起再 +1。第 7 波起小怪有概率以“词缀精英”形态出现（生命 ×3.5、掉落 ×4、必掉宝箱）。

## 9. 关卡（5 章 × 15 波）

| 章节 | 场景 | 生命 | 伤害 | 特色 |
| --- | --- | --- | --- | --- |
| 1 深夜厨房 | 木地板、面包屑、番茄酱渍 | ×1.0 | ×1.0 | 教学难度 |
| 2 荒芜菜园 | 泥土菜畦、杂草、石子 | ×1.45 | ×1.3 | 毒蜂、治疗蘑菇、虫母 |
| 3 冰封冰箱 | 结霜搁板、冰晶 | ×1.6 | ×1.35 | 大量减速与冰冻 |
| 4 城市垃圾场 | 水泥裂缝、油渍、垃圾 | ×2.1 | ×1.55 | 致盲、破甲、分裂 |
| 5 番茄酱工厂 | 金属板、警示条、酱池 | ×2.6 | ×1.8 | 全怪物混合 + 诅咒 |

- 章节倍率**渐进生效**：`1 + (倍率−1) × (0.1 + 0.9 × (波次−1)/14)`，因为每章都从 0 级开局
- 设 w = 波次−1：生命 `基础 × (1 + 成长×w + 0.03w²) × 章节系数`；伤害 `(基础 + 成长×(0.4w + 0.03w²)) × 章节系数`（前期平缓、后期加速）
- 波次时长 `min(20+5w, 60)`；刷怪间隔 `max(1.0, 2.1−0.075×波次)`；每批 `3 + 0.4×波次`；同屏上限 260

## 10. 经济与成长

| 项目 | 规则 |
| --- | --- |
| 升级经验 | `(等级+3)²` |
| 商店价格 | `基础 × (1 + 0.12(波次−1)) + 0.5×波次`，再乘折扣（上限 50%） |
| 刷新价格 | `2 + 0.75×波次 + 已刷新次数 × ceil(波次/2)` |
| 稀有度 | 随波次与幸运提升，传说从第 7 波起出现 |
| 利息 | 每个存钱罐 10%，每波上限 6×波次（防滚雪球） |
| 生命 | 每波开始回满；受击无敌 0.5 秒 |
| 控制保护 | 玩家受到的眩晕/冰冻最长 0.8 秒，之后 1.5 秒免疫 |
| 前期节奏 | 第 1~2 波每批 2 只、间隔 2.4 秒；初始武器 1~2 下击杀前期小怪 |

### 10.1 存档

- 永久进度（解锁、击杀、通关次数、最佳波次、设置）存于浏览器 localStorage
- 局内存档：每波结束进入升级/商店时自动保存，主菜单「继续游戏」可恢复；通关、阵亡或放弃时清除
- 清除浏览器数据会丢失存档

## 11. 程序化美术与动画

### 11.1 渲染
- `art/Painter.ts`：卡通着色（径向渐变体积、暗部带、底部反光、粗暖棕描边、高光点）、平滑曲线、确定性随机
- `art/RigBody.ts`：19 种身体形状 × 20 种花纹 × 11 种头顶部件
- `art/RigParts.ts`：11 种眼型、12 种嘴型、眉毛、腮红、脚、昆虫腿、翅膀、尾巴、蜗牛壳、触手、轮子
- `art/RigAcc.ts`：40+ 种配饰（厨师帽、头盔、海盗帽、巫师帽、王冠、披风、面具、护目镜、角、光环……）
- `art/WeaponArt.ts` 18 把武器、`art/ItemArt.ts` 30 种道具造型、`art/ArenaArt.ts` 5 张章节地图、`systems/Textures.ts` 子弹/特效/UI

### 11.2 部件骨骼 + 状态机（`objects/Rig.ts`）
每个角色/怪物/Boss 由 8~20 个部件组成，每帧程序驱动：

| 状态 | 表现 |
| --- | --- |
| idle | 呼吸（挤压拉伸）、随机眨眼、瞳孔注视目标 |
| move | 弹跳步伐、落地挤压、身体前倾、双脚交替、腿部摆动、翅膀扇动、尾巴/配饰惯性摆动 |
| attack | 张嘴、向前拉伸 |
| hurt | 闪白、挤眼、“哎哟”嘴型、受击抖动 |
| windup | 皱眉、咬牙、身体颤抖（冲锋/自爆预警） |
| charge | 横向拉伸、前倾 |
| stun | 螺旋眼、头顶三颗星星旋转 |
| frozen | 冰蓝着色、动作完全冻结 |
| cast | 跳起、开心眼（技能/召唤） |
| spawn | 从地面弹出（回弹缓动） |
| die | X 眼、膨胀旋转淡出 + 汁液溅射 + 地面残留污渍 |
| victory | 波次结束欢呼跳跃 |

对象池（`systems/RigPool.ts`）复用骨骼，战斗中不产生 GC 抖动。

### 11.3 外部美术替换（可选）
放入 `src/assets/` 的同名文件会覆盖程序绘制：`arena_ch1~5`、`item_<id>`、`weapon_<id>`、`icon_weapon_<id>`、`char_/enemy_/boss_<id>`（图鉴缩略图）、`sfx_*`、`bgm_*`。

## 12. 平衡方法

1. **数据驱动**：所有数值在 `src/data/`，公式集中在 `balance.ts`
2. **预算制道具**：500 件系列道具按统一强度预算生成
3. **自动化回归**：`scripts/bot.js` 机器人（躲避型 AI + 自动买第一件可买商品）以 4~6 倍速跑完整局，记录每波等级/番茄籽/生命/击杀；机器人水平远低于真人，因此目标是：
   - 第 1 章：机器人可通关（真人轻松）
   - 第 2~3 章：机器人止步中后段（真人需要构筑）
   - 第 4~5 章：机器人早期阵亡（真人需要成熟流派与操作）
4. 已据回归结果修正：后期刷怪过密、利息复利、章节开局过难、早期精英过强、第 1 波经济过少
