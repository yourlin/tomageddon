# Tomageddon (番茄酱) · Game Design Document (GDD)
[中文](../GDD.md) · **English**

## 1. Overview

| Item | Details |
| --- | --- |
| Genre | Top-down 2D horde / arena survival roguelite |
| Platform | Browser (PC + mobile landscape), Phaser 3 (WebGL) + TypeScript + Vite |
| Art | **100% procedurally drawn**: Canvas 2D cartoon rendering + part-based skeletal animation + state machine |
| Run length | About 12~18 minutes (15 waves) |
| Content | 33 characters · 18 weapons · 562 items · 25 monsters · 30 elites · 15 bosses · 12 elite affixes · 28 buffs/debuffs · 5 chapters |
| Setting | Ketchup Town is being consumed by "the rot". Tomato Sister and her produce friends fight their way from the kitchen to the Ketchup Factory to defeat the source of the rot. |

Topic docs: [Characters](CHARACTERS.md) · [Skills & Statuses](SKILLS.md) · [Weapons](WEAPONS.md) · [Items](ITEMS.md) · [Monsters](MONSTERS.md) · [Chapters](CHAPTERS.md) · [Data Tables](DATA_TABLES.md) (all generated by `npm run docs`). Back to [README](../../README.en.md).

## 2. Core Loop

```
Pick a character + chapter (each run randomly draws 2 elites and 1 boss)
  └─ Combat wave (20~60 s, boss wave 90 s; the boss enrages on timeout)
       ├─ Move to dodge bullet patterns / warning circles / lasers / charges
       ├─ Weapons auto-target and attack; the character skill is cast manually
       ├─ Buff/debuff interplay (Poison, Freeze, Curse vs Shield, Rage, Haste...)
       └─ Kills drop Seeds (XP + currency), fruit (healing), chests (items)
  └─ Wave end: Harvest, interest → level up and pick stats → open chests → shop (buy/sell, combine, reroll, lock)
  └─ Elites on waves 5/10, random "affixed elite monsters" from wave 7, boss on wave 15
Clearing a chapter unlocks the next one; achievements grant points that buy new characters
```

## 3. Controls

| Platform | Move | Skill | Pause |
| --- | --- | --- | --- |
| PC | WASD / arrow keys | Space | ESC / P |
| Mobile | Press anywhere on the left half of the screen for a floating joystick | Skill button at bottom right (shows cooldown) | Button at top right |

`EXPAND` scaling (fixed 720 logical height, width adapts from 16:9 to 21:9); portrait mode prompts to rotate to landscape; the game auto-pauses when backgrounded.

## 4. Stat System (21 stats)

Max HP, HP Regen, Life Steal, Damage %, Melee / Ranged / Elemental Damage, Attack Speed, Crit Chance, Range, Armor, Dodge, Move Speed, Luck, Harvest, Pickup Range, XP Gain, Skill Cooldown, Skill Damage, Skill Area, Skill Duration.

- Armor damage reduction `15/(15+Armor)`; attack cooldown `base/(1+AS%)`; Dodge cap 60% (Pumpkin Ghost 75%)
- Weapon damage `(base + Σ stat × coefficient) × (1+Damage%) × category multiplier`; crits × weapon crit multiplier × (1+Crit Damage%)
- Buffs/debuffs apply to stats in real time (e.g. Haste: +Move Speed +Attack Speed; Blind: -30% Range)

## 5. Buff / Debuff System (28 types)

Players and enemies share `StatusSet`: stacking, timers, damage over time, stat aggregation, shield absorption, crowd-control resistance.

| Debuffs (16) | Buffs (12) |
| --- | --- |
| Burn, Poison, Bleed, Rot (damage over time)| Haste, Rage, Shield, Regen |
| Slow, Sticky, Freeze, Stun (crowd control)| Fortify, Invulnerable, Thorns, Focus |
| Weaken, Vulnerable, Armor Break, Curse (weakening)| Barrier, Enrage, Lucky, Bloodlust |
| Blind, Confuse, Silence, Mark (special)| |

**Sources**
- Player → enemies: weapon effects (Burn/Slow/Stun), character passives, "apply on hit" items, skills, aura items
- Player self: skill self-buffs, items (on kill / on hit taken / on dodge / at wave start / periodic)
- Enemies → player: monster attacks (Venom Bee Poison, Sewer Rat Bleed, Frost Mosquito Freeze, Curse Doll Curse...), boss attacks, elite affixes (Frost/Venomous/Cursed)
- Enemy self: boss `buff` attacks (Barrier, Regen, Haste), phase-two Enrage, affixes (Shielded, Berserk, Commander aura)
- Bosses have 75% resistance to crowd-control debuffs (elites 50%) so they cannot be chain-locked

The top-left HUD shows all player status icons, stack counts and remaining-time rings; enemy bodies are tinted by status (Freeze blue, Burn orange, Poison green, Curse purple).

## 6. Characters (33)

Each character = stat modifiers + starting weapons + passive traits + a **signature talent** + an active skill + a unique look. Talents are unique mechanics that change how a character plays (e.g. Tomato Sister grows every wave, Pumpkin Ghost hits harder after dodging, Peach Angel survives one lethal hit per wave); see [Characters](CHARACTERS.md). Skill types: `nova` area burst / `dash` dash / `buff` self buff / `ghost` invulnerability / `ring` ring of bullets / `heal` drain heal / `strikes` lightning strikes / `clone` clone.

| Archetype | Characters |
| --- | --- |
| Balanced starters | Tomato Sister, Pea Soldier, Chef Yam |
| Melee tanks | Carrot Knight, Chubby Melon, Coconut Boxer, Uncle Onion, Durian Overlord, Pepper Mech |
| Ranged shooters | Corn Gunner, Cherry Gunslinger, Asparagus Archer, Blueberry Twins |
| Elemental / status | Chili Sis (Burn), Mushroom Shaman (Poison), Bitter Melon Mage (Freeze), Eggplant Mage (lightning), Dragonfruit Rider |
| Crit / assassin | Lemon Assassin, Ginger Ninja, Kiwi Detective (Mark/Vulnerable) |
| Survival / dodge | Pumpkin Ghost, Monk Gourd, Peach Angel (Shield), Count Garlic (Life Steal) |
| Economy / growth | Captain Pineapple, Lychee Princess, Strawberry Idol, Sprout Apprentice |
| Explosives / frenzy | Dr. Avocado, Wasabi Bomber, Beet Berserker, Grape Magician |

4 are unlocked by default; the rest are bought with achievement points (70–200, in starter / mid / advanced tiers), and some pricier characters also require a specific achievement (e.g. clearing a chapter or defeating a boss). See [Achievements](ACHIEVEMENTS.md).

**Ultimate forms (13)**

| Form | Description | Characters |
| --- | --- | --- |
| Nova Burst nova | Area damage + status centered on self | Tomato Sister, Chili Sis, Coconut Boxer |
| AOE Missile missile | Fires a shell at the densest enemy cluster; large explosion on impact | Captain Pineapple, Wasabi Bomber |
| Screen Clear screen | Hits every enemy on screen (low coefficient) | Eggplant Mage |
| Focused Barrage barrage | Rapid fire at a single target (Asparagus locks onto the highest-HP enemy) | Cherry Gunslinger, Asparagus Archer, Pea Soldier |
| Binding Field field | A zone lasting several seconds that repeatedly applies Slow/Freeze/Blind | Uncle Onion, Bitter Melon Mage |
| Mass Debuff curse | Applies debuffs over a wide area (Poison/Weaken/Vulnerable/Mark/Confuse), almost no damage | Mushroom Shaman, Kiwi Detective, Durian Overlord |
| Self Buff buff | Short-term stat/status buff | Strawberry Idol, Beet Berserker, Lychee Princess, Sprout Apprentice |
| Stealth ghost | Brief invulnerability + buff | Lemon Assassin, Pumpkin Ghost, Monk Gourd |
| Dash dash | Invulnerable dash, damage + status along the path | Carrot Knight, Chubby Melon, Ginger Ninja, Dragonfruit Rider |
| Multi-Strike strikes | Lightning/explosions at random points | Dr. Avocado |
| Ring Barrage ring | Fires bullets in all directions | Corn Gunner |
| Drain Heal heal | Area damage that restores HP | Count Garlic, Peach Angel, Chef Yam |
| Summon Clone clone | Summons a clone/drone that auto-fires | Blueberry Twins, Grape Magician, Pepper Mech |

**Ultimate scaling rules** (tied to the character's current stats)
- Damage = average per-hit damage of all current weapons × skill coefficient × (1 + Skill Damage%)
- Area = base radius × (1 + Range/600, clamped to 0.8~1.4) × (1 + Skill Area%)
- Duration (field/buff/invulnerability/clone/applied statuses) × (1 + Skill Duration%)
- Cooldown × (1 − Skill Cooldown%, at most −70%); cooldowns reset at the start of every wave
- Skills auto-cast by default (timed by skill form); switch to manual in Settings
- **CD is computed automatically from power** (`src/data/skills.ts`):
  `CD = (8 + 0.9×damage score + control score + buff score) × 0.65`, clamped to 8–30 s
  - Damage score = coefficient × estimated hit count (larger area and more projectiles mean more hits)
  - Control score = status strength (Stun/Freeze 4/s, Vulnerable 0.6/s, Slow 0.4/stack·s...) × hit count × 0.16
  - Buff score = self status strength + invulnerability duration×3 + heal ratio×30
  - Result: Ring Barrage about 12 s, dashes 15~19 s, Nova Bursts 27~36 s, Mass Debuffs 27~37 s, nuke-type skills around 35 s

**Skill upgrades**: 3 new stats, "Skill Damage / Skill Area / Skill Duration", together with "Skill Cooldown", are provided by 2 item series (Skill Manuals and Skill Relics, 20 items in total) and level-up choices.

## 7. Items (562)

- **42 hand-designed items** (classic items, including key ones like revive, extra weapon slot and Bubble Gum shield)
- **520 series items**: 52 themed series × 10 items (including 2 skill-upgrade series) (4 Common / 3 Rare / 2 Epic / 1 Legendary), e.g. Tomato Goods, Spices, Knives, Cookware, Frozen Treats, Thunder, Poisons, Herbs, Teas, Coffee, Desserts, Gems, Rings, Amulets, Ninja Gear, Pirate, Lab, Stars...
- **Power budget system** (`src/data/itemGen.ts`): each rarity has a fixed budget [10, 22, 40, 75], and each stat point has a unit cost (calibrated from hand-made items, e.g. 1 Max HP = 3, 1% Attack Speed = 2, 1 Armor = 4.5).
  - Rare and above carry a series-specific effect (35~45% of the budget); effect strength is converted from budget (e.g. "x% chance to Poison on hit")
  - Some Epic/Legendary items carry a drawback stat in exchange for +27% budget
  - This keeps items of the same rarity equally strong and fairly priced, avoiding "must-buy" or "junk" items
- Icons are drawn procedurally from 30 shapes × series color palettes, generated on demand

## 8. Enemies

### 8.1 Monsters (25 types, 9 AI behaviors)

Chase, wander, wind-up charge, keep distance and shoot, self-destruct, split, heal allies, summon, leave slime. Most monster attacks apply debuffs. The first few waves of each chapter are mostly Mold Blobs / Fruit Flies; signature monsters join from waves 2~4.

### 8.2 Elites (30) and Bosses (15)

- Each chapter has 6 elites + 3 bosses, randomly drawn per run → replayability
- 11 attack patterns: `ring` bullet ring, `spiral` spiral, `aimed` aimed fan, `scatter` scatter shot, `charge` telegraphed charge, `slam` telegraphed ground slam, `hazard` persistent hazard zone, `laser` telegraphed laser, `teleport` teleport, `summon` summon, `buff` empower allies
- Attacks can carry debuffs (applied when they hit the player) or buffs (for itself and nearby monsters)
- Bosses enter phase two at ≤ 50% HP (faster, shorter cooldowns, new attacks, some gain Enrage/Barrier); boss waves enrage after 90 seconds: every 10 seconds boss damage ×1.25 and one stack of enrage pressure is added (3% Max HP × 1.25^stacks per second, ignoring dodge/armor/invulnerability, uncapped), so fights can never stall

### 8.3 Elite Affixes (12)

Swift, Armored, Berserk, Regenerating, Frost, Venomous, Cursed, Shielded, Explosive, Vampiric, Thorny, Commander.
Elites: +1 random affix from wave 10, +1 from chapter 3, and another +1 from chapter 5. From wave 7, monsters have a chance to spawn as "affixed elites" (HP ×3.5, drops ×4, guaranteed chest).

## 9. Chapters (5 chapters × 15 waves)

| Chapter | Scene | HP | Damage | Features |
| --- | --- | --- | --- | --- |
| 1 Midnight Kitchen | Wooden floor, breadcrumbs, ketchup stains | ×1.0 | ×1.0 | Tutorial difficulty |
| 2 Wild Garden | Dirt beds, weeds, pebbles | ×4.6 (elites/bosses ×2.3) | ×1.6 | Venom Bees, Toxic Shrooms, Brood Mothers |
| 3 Frozen Fridge | Frosted shelves, ice crystals | ×4.0 (elites/bosses ×2.1) | ×1.55 | Lots of Slow and Freeze |
| 4 City Junkyard | Cracked concrete, oil stains, garbage | ×4.0 (elites/bosses ×2.2) | ×1.65 | Blind, Armor Break, splitting |
| 5 Ketchup Factory | Metal plates, hazard stripes, sauce pools | ×5.0 (elites/bosses ×3.0) | ×1.8 | All monsters mixed + Curse |

- Chapter multipliers **ramp in gradually**: `1 + (multiplier−1) × (0.1 + 0.9 × (wave−1)/14)`, since every chapter starts from level 0
- Let w = wave−1: HP `base × (1 + growth × w^0.9) × chapter factor` (sublinear, fast early and slower later; elites/bosses use a separate chapter multiplier); damage `(base + growth×(0.4w + 0.03w²)) × chapter factor` (gentle early, accelerating late)
- Wave duration `min(20+5w, 60)`; spawn interval `max(1.0, 2.1−0.075×wave)`; per batch `3 + 0.4×wave`; on-screen cap 260

| Chapter | Hazard | Description |
| --- | --- | --- |

| Kitchen | Drain Grate | Manhole covers in the four corners; from wave 3 monsters crawl out periodically |

## 10. Economy and Progression

| Item | Rule |
| --- | --- |
| Level-up XP | `(level+3)²` |
| Shop price | `base × (1 + 0.12(wave−1)) + 0.5×wave`, then multiplied by discount (capped at 50%) |
| Reroll price | `2 + 0.75×wave + rerolls so far × ceil(wave/2)` |
| Reroll scaling | The more unbought, unlocked items remain, the pricier a reroll: 4 left ×1.2 … 1 left ×0.6; buying everything restocks for free |
| Rarity | Improves with wave and Luck; Legendary appears from wave 7 |
| Interest | 10% per Piggy Bank, capped at 6×wave per wave (prevents snowballing) |
| Uncollected Seeds | Not auto-collected at wave end; they go into a bonus pool, and next wave every Seed you pick up grants the same amount again until the pool runs out |
| HP | Fully restored at the start of each wave; 0.5 s invulnerability after being hit |
| CC protection | Stun/Freeze on the player lasts at most 0.8 s, followed by 1.5 s of immunity |
| Early pacing | Waves 1~2 spawn 2 per batch at 2.4 s intervals; the starting weapon kills early monsters in 1~2 hits |

### 10.1 Saves

- Permanent progress (unlocks, kills, clear count, best wave, settings) is stored in browser localStorage
- Run saves: auto-saved at the end of each wave when entering level-up/shop, resumable via "Continue" in the main menu; cleared on clear, death or abandon
- Clearing browser data deletes saves

## 11. Procedural Art and Animation

### 11.1 Rendering
- `art/Painter.ts`: cartoon shading (radial-gradient volume, shadow band, bottom rim light, thick warm-brown outline, highlight dots), smooth curves, deterministic randomness
- `art/RigBody.ts`: 19 body shapes × 20 patterns × 11 head parts
- `art/RigParts.ts`: 11 eye types, 12 mouth types, eyebrows, blush, feet, insect legs, wings, tails, snail shells, tentacles, wheels
- `art/RigAcc.ts`: 40+ accessories (chef hat, helmet, pirate hat, wizard hat, crown, cape, mask, goggles, horns, halo...)
- `art/WeaponArt.ts` 18 weapons, `art/ItemArt.ts` 30 item shapes, `art/ArenaArt.ts` 5 chapter maps, `systems/Textures.ts` bullets/effects/UI

### 11.2 Part-Based Skeleton + State Machine (`objects/Rig.ts`)
Each character/monster/boss is made of 8~20 parts, driven procedurally every frame:

| State | Behavior |
| --- | --- |
| idle | Breathing (squash and stretch), random blinks, pupils tracking the target |
| move | Bouncy steps, landing squash, forward lean, alternating feet, leg swing, wing flaps, tail/accessory inertia sway |
| attack | Mouth opens, stretches forward |
| hurt | White flash, squinting, "ouch" mouth, hit shake |
| windup | Frown, gritted teeth, body trembling (charge/self-destruct warning) |
| charge | Horizontal stretch, forward lean |
| stun | Spiral eyes, three stars circling overhead |
| frozen | Icy blue tint, fully frozen motion |
| cast | Jump, happy eyes (skill/summon) |
| spawn | Pops out of the ground (bounce easing) |
| die | X eyes, swell-spin fade-out + juice splatter + lingering ground stain |
| victory | Cheering jump at wave end |

An object pool (`systems/RigPool.ts`) reuses skeletons, so combat produces no GC stutter.

### 11.3 External Art Overrides (optional)
Files with matching names placed in `src/assets/` override the procedural art: `arena_ch1~5`, `item_<id>`, `weapon_<id>`, `icon_weapon_<id>`, `char_/enemy_/boss_<id>` (codex thumbnails), `sfx_*`, `bgm_*`.

## 12. Balancing Approach

1. **Data-driven**: all values live in `src/data/`, with formulas centralized in `balance.ts`
2. **Budgeted items**: 500 series items are generated from a unified power budget
3. **Automated regression**: the `scripts/bot.js` bot (dodge-focused AI + auto-buys the first affordable item) plays full runs at 4~6× speed, logging level/Seeds/HP/kills per wave; the bot plays far worse than a human, so the targets are:
   - Chapter 1: the bot can clear it (easy for humans)
   - Chapters 2~3: the bot stops in the mid-to-late waves (humans need a build)
   - Chapters 4~5: the bot dies early (humans need a mature build and good play)
4. Fixed based on regression results: overly dense late-game spawns, compounding interest, overly hard chapter openings, overly strong early elites, too little economy on wave 1

## 13. Technical Architecture

```
src/
  data/      stats balance statuses weapons items itemGen describe characters enemies bosses chapters
  art/       Painter RigSpec RigBody RigParts RigAcc WeaponArt ItemArt ArenaArt
  objects/   Rig (skeleton + state machine) Enemy (AI + attacks + affixes) Bullet
  systems/   RunState Status RigPool WeaponSystem SkillSystem Grid Fx Textures Assets Audio Save Controls
  scenes/    Boot Menu CharSelect Game Hud LevelUp Shop Pause Result Codex Settings
  ui/        UI Portrait
```

Performance: a spatial hash grid handles collision/targeting with no physics engine; enemies, bullets, skeletons, damage numbers and stains are all pooled; WebGL batch rendering. Measured 120 FPS on the chapter 5 boss wave (Mac Chrome).
