# 开发者界面（`?dev`）路线图

目标：让开发者界面从"能调构筑、能看怪"变成**做平衡、做内容、查 bug 的主力工具**，并直接服务于 1.4.0（危机等级、遗物、无尽、角色任务等新系统都要能在这里调和测）。

- ★ = 核心；☆ = 加分项
- 全部为本地前端功能，不需要服务器
- 现状：构筑 / 武器 / 技能 / 怪物 / 测试记录 5 个页签，沙盒（无敌、倍速、叠加层、木桩、TTK 测试），顶部快捷栏（角色 `[ ]`、怪物 `, .`）

## 开发顺序

| 里程碑 | 内容 | 为什么先做 |
|---|---|---|
| D1 | A 基础体验 + B 沙盒控制 | 现在每天都在用，痛点最多 |
| D2 | C 构筑 + D 怪物 + E 武器 / 技能 | 平衡调整的主战场 |
| D3 | F 测试与对比 + G 批量模拟 | 把"感觉"变成数据 |
| D4 | H 1.4.0 新系统支持 | 跟着 1.4.0 开发同步做 |
| D5 | I 数据编辑 + J 调试 + K 内容 / 美术 + L 工程 | 长期效率 |

- [x] ★ A2 面板状态持久化：当前页签、筛选条件、滚动位置、快捷栏选择刷新后保留
- [x] ★ A3 全局命令面板（`Ctrl+K`）：搜索角色 / 武器 / 道具 / 怪物 / 操作，回车直达
- [x] ★ A4 快捷键总览（`?` 弹出），所有快捷键可在设置里改
- [x] ★ A5 角色快捷栏加头像缩略图，下拉框改为可搜索的网格选择器
- [x] ★ A6 怪物快捷栏加缩略图条（当前筛选下所有怪物一排小图，点哪个生成哪个）
- [x] ☆ A7 面板浮动 / 弹出为独立窗口（`window.open`，双屏时游戏全屏、面板放另一屏）

## B. 沙盒控制

- [x] ★ B1 单步执行：暂停后按帧 / 按 0.1 秒前进（排查碰撞、判定时机）
- [x] ★ B2 慢放 ×0.25 / ×0.5（看特效和弹道），现有倍速只有加速
- [x] ★ B3 点击画面放置：选中怪物后在鼠标位置生成；拖动已生成的目标
- [x] ★ B4 相机控制：缩放、平移、跟随玩家 / 跟随目标 / 自由镜头
- [x] ★ B5 玩家传送（点击地图传送）、锁定玩家位置
- [x] ★ B6 地形：按章节切换场景与地形机关，单独开关每种机关
- [x] ★ B7 快照：一键保存 / 恢复沙盒完整状态（构筑 + 场上怪物 + 位置），用于复现 bug
- [x] ☆ B8 时间轴回放：记录最近 30 秒，可拖进度条回看
- [x] ☆ B9 刷怪剧本：按时间表批量生成（"0 秒 20 只霉菌，5 秒 1 只精英…"），可保存
- [x] ☆ B10 模拟真实波次：按章节和波次跑正常刷怪逻辑，但保留无敌、倍速、统计
- [x] ☆ B11 碰撞框 / 受击框 / 弹道路径可视化叠加层
- [x] ☆ B12 性能叠加层：实体数、弹幕数、对象池占用、帧耗时曲线

## C. 构筑

- [x] ★ C1 构筑对比：A / B 两套构筑并排显示属性差异和期望 DPS 差异
- [x] ★ C2 一键"典型构筑"：按角色 + 波次自动生成"正常玩家此时大概的构筑"（基于机器人选择逻辑）
- [x] ★ C3 从真实存档导入：读取正在进行的对局或最近的历史记录，载入为构筑
- [x] ★ C4 属性来源分解：鼠标悬停最终属性，显示来自角色 / 天赋 / 道具 / 升级 / 词条各多少
- [x] ★ C5 预设分组、搜索、排序；预设显示最后一次测试结果
- [x] ☆ C6 构筑分享码（与 1.4.0 J2 共用格式）
- [x] ☆ C7 天赋树可视化编辑（直接点节点加减，而不是只有"存档 / 无 / 满级"三档）
- [x] ☆ C8 武器栏拖拽排序、拖拽合成

## D. 怪物

- [x] ★ D1 怪物属性实时编辑：生命、伤害、速度、半径、招式参数，改完立刻作用于场上目标（不写回源码）
- [x] ★ D2 Boss 阶段控制：直接跳到二阶段、狂暴、指定血量百分比
- [x] ★ D3 招式时间轴：显示 Boss 每个招式的冷却进度和下一次出招时间
- [x] ★ D4 词缀组合预设与"全词缀"压力测试
- [x] ★ D5 全部类别：一个列表看所有章节的小怪 + 精英 + Boss，可按章节、行为、招式类型筛选
- [x] ☆ D6 怪物 AI 状态可视化（当前目标、行为状态、移动方向）
- [x] ☆ D7 刷怪池可视化：某章每波各怪物出现概率的堆叠图
- [x] ☆ D8 强度矩阵改成热力图，并标出与玩家期望 DPS 的比值（"这只怪在 W10 需要打几秒"）

## E. 武器 / 技能 / 道具

- [x] ★ E1 武器 DPS 曲线：某把武器 T1~T4、+0~+10 打造下的 DPS 折线
- [x] ★ E2 武器排行榜：在当前构筑属性下所有武器的期望 DPS 排序，可按流派筛选
- [x] ★ E3 进化路线图：每把可进化武器的需求、进化前后数值对比
- [x] ★ E4 道具页（新页签）：所有道具的效果、价格、获取限制，一键加入构筑
- [x] ★ E5 技能参数实时编辑：冷却、范围、伤害系数、持续时间
- [x] ☆ E6 词条模拟：给 T3/T4 武器洗练 1000 次，统计词条分布和期望价值
- [x] ☆ E7 打造模拟：+0 到 +10 的期望花费和成功率分布
- [x] ☆ E8 状态效果页：所有 buff / debuff 的数值、叠层、持续时间，可对玩家或目标直接施加

## F. 测试与对比

- [x] ★ F3 测试结果导出 CSV / Markdown
- [x] ★ F4 测试固定随机种子，保证可重复
- [x] ☆ F5 测试结果图表：TTK 随波次变化曲线

- [x] ★ H4 无尽模式：直接跳到任意波次（30 / 45 / 60），测试超级 Boss 和变异词缀
