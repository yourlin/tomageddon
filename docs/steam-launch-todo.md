# Steam 上线 Todo List

按执行顺序排列。关键路径是两个硬性等待期：支付上架费后至少 30 天才能发售，"即将推出"商店页至少公开 2 周。这两项和技术改造可以并行，建议第一周就交费，并尽快挂出商店页。

## 一、账号与资质（第 1 周）

- [ ] 注册 Steamworks 开发者账号（个人身份即可，不需要公司资质）
- [ ] 完成身份验证（证件信息与银行、税务资料保持一致）
- [ ] 确认开户行可接收境外美元电汇（SWIFT），了解所需资料和手续费
- [ ] 填写银行收款信息
- [ ] 完成税务问卷 W-8BEN，按中美税收协定申请优惠预扣税率
- [ ] 填写欧盟 DSA 交易者信息（会在商店页公开；不想公开个人地址的话，先评估是否注册公司）
- [ ] 支付 100 美元上架费（游戏收入达到 1000 美元后退还），从这天起算 30 天等待期

## 二、商店页（尽早挂出，积累愿望单）

- [ ] 中英文简介和详细描述（README 可作素材）
- [ ] 各尺寸胶囊图：header、small、main、vertical、library 等（图上只放游戏美术和标题，不写评分、奖项或促销文字）
- [ ] 至少 5 张截图
- [ ] 预告片（可用现有 promo 视频）
- [ ] 内容调查问卷（暴力程度等）
- [ ] AI 生成内容披露（如实申报）
- [ ] 系统需求、支持语言（中文、英文）
- [ ] 确定定价：免费，或付费并加入网页版没有的内容（成就、云存档、额外内容）
- [ ] 提交商店页审核（约 1-5 个工作日）
- [ ] 公开"即将推出"页面，至少满 2 周后才能发售

## 三、技术改造（基础约 2-3 天，Steam 功能另需约 2-3 天）

- [ ] 平台适配层阶段 0：`src/platform/` 骨架、Web 实现、ESLint 约束
- [ ] 存储层改为启动时预读进内存缓存、写入时异步落盘；Steam 版写入 `userData` 目录，原子写，退出时 flush
- [ ] 首次启动时，把 localStorage 里的旧存档导入新存储
- [ ] Electron 打包 Windows 版，新增 `build:steam` 脚本
- [ ] 全屏和窗口：改用 `BrowserWindow.setFullScreen`，提供窗口/全屏切换和分辨率设置，关闭"请旋转屏幕"等提示
- [ ] 外链改为用系统浏览器打开（`shell.openExternal`）
- [ ] Steam 版隐藏"支持作者"捐赠入口
- [ ] 窗口失焦、最小化或 Steam 浮层打开时自动暂停
- [ ] 接入 `steamworks.js`：成就同步、"正在游玩"状态
- [ ] 让 Steam 浮层（Shift+Tab）在 Electron 中正常显示
- [ ] 在 Steamworks 后台配置 Auto-Cloud，同步存档目录
- [ ] 构建时排除 `public/promo/*.webm`（约 23 MB）
- [ ] （可选）手柄支持，有助于 Steam Deck 认证

## 四、构建与发布

- [ ] 用 SteamPipe（steamcmd）上传构建
- [ ] 在 Steam 客户端实测：存档、云同步、成就、浮层、全屏、外链
- [ ] 提交构建审核（约 1-5 个工作日，被打回则修改后重新提交）
- [ ] 确认已满 30 天等待期、商店页已公开满 2 周，然后定下发售日期
- [ ] 发售

## 五、发售后

- [ ] 在国内申报境外收入的个人所得税（已在美国预扣的税款可以抵免）
- [ ] 结汇超过每年 5 万美元便利额度的部分要走额外手续
- [ ] 收入起来后评估是否注册公司（隐私、税务、发票、国内版号）

> 注：费用、分成、税率和审核时长以 Steamworks 官方文档为准；税务和法律问题建议咨询专业人士。
