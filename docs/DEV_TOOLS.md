# 开发者界面（`?dev`）使用说明

在游戏地址后加 `?dev` 打开（例如 `http://localhost:5173/?dev`）。开发者模式下存档不写盘，沙盒里的击杀、天赋改动、图鉴发现都只留在内存里。构建时设置 `VITE_DISABLE_DEV=1` 可以彻底关闭 `?dev`，开发者分包也不会生成。

## 面板

两种布局，顶部「◫ / ▣」切换：

- **工作室**（默认）：游戏画面居中占满。顶栏是播放控制（暂停 / 单步 / 倍速 / 释放技能 / 清场 / 重启），左侧是页签栏，点页签从左边拉出抽屉，再点一次当前页签（或顶栏「⇤」）收起，画面随之变大；底栏左边是角色切换，右边是作弊与叠加开关；实时数据浮在画面右上角，可折叠成一行。拖抽屉右边缘调宽。
- **停靠**：整块面板停在一侧。拖动面板边缘调宽；顶部按钮可切换左右停靠，或「⧉ 弹出」到独立窗口（双屏时游戏全屏、面板放另一屏，关掉窗口自动回到页面里）。

两种布局都可以切换紧凑 / 宽松密度。

**快速开局**：顶栏「快速开局 第 X 章 第 Y 波 ▶」一键进入指定章节与波次的**真实对局**：只带开局武器，等级按每波约 1.3 级、升级加点随机分配，资金按期望收入估算，先打开游戏里真实的商店（货架品质看幸运）自己采购、合成；点「下一波」开打，之后计时、掉落番茄籽与经验、升级、波次结算、下一波商店都和正式对局一样，可以一直玩下去（关掉旁边的「无敌」会真实阵亡并结算）。每进入一波，武器、道具、波次和剩余番茄籽同步回构筑页（仓库里的武器、真实对局里的升级选择不同步）。第 1 波没有商店，直接开打。点「重启沙盒」回到普通沙盒。沿用当前角色、天赋与危机等级；命令面板里也能执行。
- 布局、页签、筛选条件、滚动位置、宽度和快捷键都记在 localStorage，刷新后保留。
- 顶部 toast 点一下可以展开操作日志（最近 50 条）。页面报错会自动记录到「调试」页，并附当时的构筑与沙盒快照。

## 快捷键（按 `?` 查看，可点击改绑）

| 按键 | 作用 |
|---|---|
| `Ctrl+K` | 命令面板：搜索页签 / 角色 / 怪物 / 武器 / 道具 / 操作，回车执行 |
| `[` `]` | 上一个 / 下一个角色 |
| `,` `.` | 清场并生成上一个 / 下一个怪物 |
| `` ` `` | 暂停 / 继续 |
| `\` | 单步 1 帧 |
| `Ctrl+Z` `Ctrl+Y` | 撤销 / 重做构筑改动 |
| `F6` `F7` | 保存快照 / 恢复最近快照 |

焦点在文字或数字输入框里时快捷键不生效。WASD、方向键、空格、Esc、P 留给游戏。

## 页签

| 页签 | 内容 |
|---|---|
| 构筑 | 角色、章节、波次、等级、资金；商店模拟（目录 / 随机货架）；升级加点；预设（「分组/名称」分组、搜索、最近测试）；C1 A/B 对比、C2 典型构筑、C3 从存档导入、C4 属性来源分解、C6 分享码、C7 天赋树编辑 |
| 武器 | 所有武器在当前属性下的伤害 / 冷却 / 射程 / 期望 DPS，单独试用 |
| 分析 | E1 DPS 曲线（品质、打造；可视化选武器，按标签 / 类别筛选，超武可单独看；附平衡测试实测的 T1–T4 实战转换率，数据是 `reports/weapon-eff.json`，每次平衡测试自动生成，也可 `node scripts/weapon-eff.mjs` 重算）、E2 武器强弱榜（流派 近战/远程/元素/光环 与类别筛选；纸面 vs 实际 DPS、转换率、使用率、通关率差、伤害占比、冷却、射程、价格、性价比，可按任一项排序）、E3 进化路线、E6 洗练模拟、E7 打造模拟 |
| 技能 | 所有角色技能；E5 当前角色技能参数实时编辑 |
| 怪物 | 小怪 / 精英 / Boss / 全类别（按行为、招式筛选）；场上目标实时编辑、Boss 血量与阶段控制、招式时间轴；词缀组合与全词缀压力测试；刷怪池概率图；强度热力图（按构筑击杀秒数着色）；AI 状态叠加层 |
| 道具 / 状态 | 道具一览（一键加入构筑）；状态效果数值，可对玩家或目标施加 |
| 沙盒 | 慢放、单步、镜头、点击放置 / 传送、锁定玩家、地形机关开关、真实刷怪、快照、30 秒回放、刷怪剧本、碰撞框、性能数据 |
| 测试 | TTK 记录；测试套件（构筑 × 怪物 × 波次，固定种子一键重跑）、两次运行对比、回归基线、CSV / Markdown 导出、TTK 随波次曲线 |
| 批量 | 无头机器人对局（隐藏 iframe 并行）：通关率、死亡波次分布、武器 / 道具选取率与胜率、与上次对比；失败对局载入沙盒复盘 |
| 报告 | 查看 `npm run balance`（`scripts/batch.mjs`）生成在 `reports/` 的平衡报告，ECharts 图表可交互；下拉切换历史报告、可全屏查看（Esc 退出）或新窗口打开。只在 `npm run dev` / `npm run preview` 的服务器上可用（接口 `/__balance-reports/`），静态部署没有 |
| 数值 | 任意数据表数字字段临时覆盖（可选刷新后保留）、覆盖项列表、导出为代码补丁、平衡曲线滑块预览 |
| 调试 | 实体检查器、事件流（伤害 / 治疗 / 状态 / 技能 / 拾取 / 击杀）、报错、场景栈、存档与 localStorage |
| 内容 | Rig 动画预览、贴图浏览、特效预览、音效 / 音乐试听、多语言检查、UI 场景直达 |

## 常用工作流

**复现 bug**：沙盒里摆好场面 → `F6` 保存快照 → 改代码刷新 → `F7` 回到同一场面。快照可「复制」成 JSON 发给别人，对方用「从剪贴板导入」。

**调一把武器**：「数值」页改字段（例如武器 `dmg`）→ 「测试」页跑套件，与基线对比 → 满意后「复制为代码补丁」粘进 `src/data/weapons.ts`。

**检查一章难度**：构筑页生成该章 W10 的典型构筑 → 怪物页打开热力图，看哪只怪击杀秒数明显偏离 → 「批量」页跑 20 局看通关率。
