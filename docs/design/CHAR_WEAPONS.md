# 角色专属标签、武器与超武方案（草案）

> 状态：已实现第一版。配合 [DOUBLE_SYNERGY.md](DOUBLE_SYNERGY.md)：双契合武器获得武器契合技和标签特性强化。

## 1. 目标

1. 39 名角色的契合标签组合**互不相同**，双契合武器和角色人设、天赋方向对得上。
2. 每名角色双契合基础武器 2–5 把，并且至少有 1 把**主题对得上**的双契合超武。
3. 只靠现有 19 个标签和 119 把商店武器做不到（钝器、狙击、毒气、光环武器太集中），所以新增标签、基础武器和超武。

## 2. 合成标签规则（已实现）

- 同名两把合成（T1→T3、精炼 T4）：标签不变。
- 两把不同武器合成（融合 T4、超武）：标签 = 两把材料标签的**并集**，不再按合成后的效果重新判定。
- 所以超武可能只有原武器的标签（两把同名 T4 合成），也可能带多个标签（两把不同 T4 合成）。
- 下面每把新超武都写明两把材料，材料的标签并集覆盖对应角色的两个契合标签。

## 3. 光环专长角色

按天赋和特性重新确认，真正以光环为核心的只有 3 名，契合标签都带「光环」；其他角色不再用光环标签。

| 角色 | 光环相关的设定 | 契合标签 |
|---|---|---|
| 大蒜伯爵 | 周身 160 范围血雾，流血吸血 | 光环＋蔬果 |
| 芋头术士 | 只能装备光环武器，周身 170 范围灼烧，灼烧伤害 ×1.25 | 光环＋火焰（原来是光环＋暴击，改成跟灼烧天赋一致） |
| 榴莲霸王 | 周身 160 范围虚弱、中毒 | 毒气＋光环（原来是毒气＋元素） |
| ~~菠萝蜜卫士~~ | 荆棘反伤、射刺针，不是光环 | 改为锋利＋穿透 |
| ~~卷心菜老兵~~ | 坚韧、复活、净化，不是光环 | 改为厨具＋钝器（锅盾） |
