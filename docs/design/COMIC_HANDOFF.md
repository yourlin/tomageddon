# 交接：章节开场四格漫画

剧情见 [STORY.md](STORY.md)。本文说明漫画在游戏里怎么播放、插画怎么接入、还剩哪些事。

## 现状

- 播放流程已完成：第一次进入某章（选关界面点「出发！」）先播该章四格漫画，再进战斗；选关界面「📖 本章故事」可随时回看；看过的章节记在存档 `save.meta.comicsSeen`。
- 画面目前是**占位版**：用游戏里的角色 / 怪物 Rig、章节场地缩略图和 emoji 拼出来的，效果不满意，需要换成手绘插画。
- 插画接入点已做好：**把图片放进指定目录即可替换，不需要改代码**。某一格有插画就显示插画，没有就继续显示占位版，所以可以一格一格地换。

## 插画规格

| 项 | 要求 |
|---|---|
| 位置 | `src/assets/comics/`（目录不存在就新建） |
| 文件名 | `ch{章}-{格}.{png\|jpg\|webp}`，例如 `ch1-1.png` … `ch7-4.webp`，共 28 张。格子顺序：1 左上、2 右上、3 左下、4 右下 |
| 比例 | 约 **1.9 : 1**（横版）。1280×720 屏幕上每格约 554×290，1920×1080 下约 870×455 |
| 建议尺寸 | 1600×840（2× 清晰度，兼顾高分屏） |
| 裁切 | 按 cover 铺满格子、居中裁切。屏幕比例不同时左右或上下会被裁掉一点，**主体放在中间 85% 范围内** |
| 文字 | **不要把文字画进图里**。游戏有中英文两版，旁白 / 对白 / 拟声由游戏叠加在格子**底部字幕条**里（约占格子底部 20–25% 高度），这块区域不要放关键画面 |
| 格式 | 推荐 webp（质量 80 左右，单张控制在 200 KB 内）；png 也可以 |
| 风格参考 | 游戏内角色形象可在开发者界面（`?dev`）「工具 → 内容」页签或 `docs/images/char/`、`docs/images/boss/`、`docs/images/map/` 查看 |

拟声字（如「咕嘟……咕嘟……」「啪！！」）在插画格里只有当这一格没有旁白和对白时才显示在字幕条里。如果想要漫画式的拟声效果，可以直接画进图里——拟声不需要翻译时没有问题，需要中英文两版时，请画成无文字的效果线。

## 每一格画什么

以 [STORY.md](STORY.md) 的「分章剧情」表格为准，每章 4 行对应 4 格；表里的「场景」列就是画面说明，「文字」列由游戏叠加，不需要画。

几个固定约束：

- 主角是番茄妹；伙伴按章节加入（第 2 章胡萝卜骑士、第 3 章辣椒姐、第 4 章玉米枪手，第 5 章三人齐聚）。
- **第 1–5 章的 Boss 每局随机抽取**（每章 3 选 1），漫画里只能画剪影 / 影子，不能画出具体是哪个 Boss。第 6 章枯萎园丁、第 7 章腐土之母和腐烂之王是固定 Boss，可以正常画。
- 第 7 章是隐藏章节，第 6 章需要危机 5 解锁；它们的漫画只有解锁后才能看到，可以放心画剧情后半段。

## 怎么在游戏里看效果

1. 把图片放进 `src/assets/comics/`。dev 服务器会热更新；`vite build` 后才会进正式包。
2. 打开游戏 → 选关界面 → 选章节 → 点「📖 本章故事」回看（未解锁的章节不能看）。
3. 想重新体验「第一次进入自动播放」：浏览器控制台执行
   ```js
   const s = JSON.parse(localStorage.tomato_sister_save_v1); delete s.meta.comicsSeen; localStorage.tomato_sister_save_v1 = JSON.stringify(s); location.reload();
   ```
4. 操作：点击 / 任意键翻下一格，Esc 或右上角「跳过」直接跳过。

## 代码位置

| 文件 | 内容 |
|---|---|
| `src/data/comics.ts` | 7 章剧本：每格的中英文旁白 / 对白 / 拟声、占位版的演员与道具布局、格子效果（震屏 / 闪白 / 速度线）。**改台词改这里** |
| `src/scenes/ComicScene.ts` | 漫画场景：2×2 排版、逐格出现、插画加载（`ART` / `artUrl`）、插画格字幕条（`drawArtPanel`）、占位版绘制（`drawPanel`） |
| `src/scenes/CharSelectScene.ts` | `begin()` 首次进入章节时跳转漫画；「📖 本章故事」按钮 |
| `src/systems/Assets.ts` | 启动加载的图片 glob 排除了 `assets/comics/**`，漫画插画只在漫画场景里按需加载当前章节的 4 张 |
| `src/systems/Save.ts` | `meta.comicsSeen?: number[]`（可选字段，旧存档无需迁移） |
| `tests/comics.test.ts` | 校验剧本数据：每章 4 格、演员 id 存在、对白指向格内演员、第 1–5 章 Boss 必须是剪影 |

## 可能要做的后续

- 全部 28 格都换成插画后，占位版的演员 / 道具数据（`comics.ts` 里的 `actors`、`props`、`bg`）就用不到了，可以删掉以减小包体；保留 `caption` / `say` / `sfx` 文字。
- 如果希望对白以气泡形式出现在插画上而不是字幕条，需要给每格加气泡坐标字段（`say` 里加 `x` / `y`），并在 `drawArtPanel` 里改用 `bubble()` 绘制。
- 图鉴里目前没有「故事」入口，只能在选关界面回看。
- 英文台词是按中文剧本翻译的初稿，可以再润色。
