# Boss 阶段门槛设计方案（草案）

> 状态：设计已确认，在场地系统（`ARENAS.md`）完成后实现。目标版本 0.7.0。

## 1. 问题与目标

上一轮全角色 7 章测试（546 局）里，章节 Boss 被打死的用时：

| 章节 | 最快 10% | 中位数 | 不到 20 秒 |
|---|---|---|---|
| 1 | 9.9 秒 | 22 秒 | 44% |
| 2 | 10.4 秒 | 24 秒 | 38% |
| 3 | 18.1 秒 | 33 秒 | 17% |
| 4 | 15.2 秒 | 38 秒 | 21% |
| 5 | 6.7 秒 | 22 秒 | 50% |
| 6 | 7.0 秒 | 11 秒 | 100% |
| 7 | 10.9 秒 | — | 100% |

强构筑几秒就把 Boss 打死，Boss 的招式根本来不及放。现有的「二阶段」只是血量 50% 时加一两个招式、提速，玩家多数时候看不到。

**目标**

1. 任何构筑打 Boss 都至少 **20 秒**，弱构筑也不会被拖得更久（不额外加血）。
2. 每个 Boss 分 **3 个阶段**（真结局 Boss 4 个），每个阶段的招式组合、节奏、场地压力都不同，阶段切换有演出。
3. 尽量复用现有 11 种招式类型（ring / spiral / aimed / charge / summon / slam / hazard / laser / teleport / buff / scatter），新增的只有阶段框架本身。

## 2. 通用框架

### 2.1 阶段与门槛

- 默认：普通 Boss **3 阶段**，门槛在生命 **70%** 和 **35%**；真结局 Boss（腐烂之王）**4 阶段**，门槛在 **75% / 50% / 25%**。
- **阶段数与门槛位置按 Boss 单独配置**（数据里每个阶段写自己的 `at`），以后可以给个别 Boss 改成 2 或 4 阶段、挪动门槛，不用改代码。
- 精英不做阶段（保持现状），本方案只改章节 Boss 与真结局 Boss。

### 2.2 门槛锁血（保证最短战斗时间）

- 每个阶段有**最短时长**：第 1、2 阶段各 **6 秒**（真结局各 5 秒）。
- 阶段计时没到最短时长时，Boss 生命**不会低于下一道门槛**：超出的伤害作废，跳字显示灰色「坚韧」，让玩家知道不是没打中。
- 到达门槛且最短时长已满，进入**转阶段**。

### 2.3 转阶段（3 秒）

1. Boss 进入「蜕变」状态 **3 秒**：无敌（跳字显示「无敌」）、不移动，播放该 Boss 专属的转阶段演出。
2. 转阶段期间放一次**专属转场招式**（见各 Boss 设计），给玩家一个明确的「躲」的时刻。
3. 清掉场上已有的 Boss 弹幕，避免和新阶段叠在一起。
4. 结束后切换到新阶段的招式表，招式冷却从 1.5 秒开始，不会刚切换就同时放出全部招式。

### 2.4 最短战斗时间的推算

第 1 阶段 6 秒，加转阶段 3 秒，再加第 2 阶段 6 秒、转阶段 3 秒，最后第 3 阶段打掉剩下的 35% 生命，最快约 2–3 秒，合计约 **20 秒**。

弱构筑本来就打得慢，门槛锁血不会触发，只多出 2 次 × 3 秒的转阶段，战斗大约长 6 秒。

### 2.5 转阶段动画（3 秒时间轴）

每次转阶段都播放一段固定节奏的动画。通用部分由框架统一实现，每个 Boss 再叠加自己的专属表现（见第 3 节各 Boss 的「动画」行）。

| 时间 | 段落 | 画面 | 实现手段 |
|---|---|---|---|
| 0.0–0.4 秒 | **定格** | 门槛被打破的瞬间全场慢动作（游戏速度 ×0.25，持续 0.3 秒）；Boss 闪白，血条在门槛刻度处「碎裂」；屏幕白闪一帧 | 全局时间缩放、Rig 闪白、血条碎片粒子 |
| 0.4–1.8 秒 | **蓄势** | 镜头按该 Boss 的运镜方案移动（见 2.5.1）；Boss 播放施法动作并持续颤抖，体型在 1.0 和 1.15 之间脉动；四周粒子向 Boss 汇聚，身后光环逐渐变亮；屏幕上方滑入阶段名横幅 | 镜头缩放、Rig `cast` 动作加抖动 tween、汇聚粒子、横幅 |
| 1.8–2.4 秒 | **爆发** | Boss 外观切换到新阶段形态（换色、换配件或体型变化），向外爆出冲击波：场上 Boss 弹幕全部碎成火花消失，玩家被轻推开；同时放出专属转场招式；屏幕震动 | `nova` / `explosion` 特效、敌弹清除特效、轻击退、`shake` |
| 2.4–3.0 秒 | **收势** | 镜头回到原位，横幅淡出，Boss 摆出新阶段的待机姿势后恢复行动 | 镜头复位、Rig 待机 |

#### 2.5.1 运镜

运镜按 Boss 和场景单独设计，在数据里用 `camera` 字段描述，框架提供几种基本动作组合：

| 动作 | 说明 | 适合 |
|---|---|---|
| 推近 `push` | 镜头向 Boss 推近 5–15% 并对准它 | 体型小、变身动作在身上的 Boss（霉菌大王、冰淇淋暴君） |
| 拉远 `pull` | 镜头拉远到能看清整个场地 | 转场招式覆盖全场的（工厂主脑全屏警报、番茄酱海怪酱潮） |
| 跟随 `track` | 镜头跟着 Boss 移动（钻地、升空、冲刺） | 鼹鼠大将钻地、废铁巨龙升空、番茄酱海怪潜入 |
| 偏移 `pan` | 镜头先移到转场招式的落点，再移回玩家 | 落点不在玩家附近的大招（腐土之母的扩散圈） |
| 抖动 `shake` | 不同强度的震屏 | 砸地、爆发 |

- 每个 Boss 的转阶段写一段运镜序列，比如「推近 10% → 爆发时抖动 → 拉远看全场 → 复位」。
- 场地小（比如第 1 章）就少用拉远，场地大就多用拉远让玩家看到全局，具体见 `ARENAS.md`。
- 运镜期间玩家仍然可以移动；镜头最远只离开玩家 40% 屏幕宽度，保证玩家不会出画。

通用规则：

- **可关闭**：慢动作、运镜、震屏都跟随设置里的「屏幕震动」开关；关掉后只保留特效和横幅，时间轴长度不变。
- **安全**：整个转阶段 Boss 无敌且不造成接触伤害；只有专属转场招式会造成伤害，并且一定先有预警。
- **音效**：门槛碎裂一声，爆发一声低音冲击。第 3 阶段起背景音乐切到更紧张的一层（如果 Music.ts 支持分层；不支持就只提高节奏）。
- **测试模式**（headless）：跳过慢动作和镜头动画，只保留 3 秒时长，保证测试结果和实际节奏一致。

### 2.6 每个阶段的常驻外观

- **阶段 Ⅰ**：原始外观。
- **阶段 Ⅱ**：主色调变深 10%，身上出现该 Boss 的「伤痕」配件（裂纹、缺口、冒烟），并带一圈淡色光环。
- **最终阶段**：不做统一的「狂怒」形态，外观、移速、光环都由各 Boss 自己设定（见第 3 节各 Boss 的「动画」行；表里写「附带狂怒」的是该 Boss 自己的设定）。

### 2.7 表现与提示

- **Boss 血条**：在 70% 和 35% 处加刻度，当前阶段用罗马数字标在血条左侧（Ⅰ / Ⅱ / Ⅲ）。破门槛时刻度处碎裂，罗马数字翻转到下一个。
- **转阶段横幅**：屏幕中上方显示「Boss 名 · 阶段名」，比如「霉菌大王 · 孢子爆发」，在蓄势段滑入、收势段淡出。
- 第 3 阶段的难度只来自招式本身，不做统一的伤害加成。

### 2.8 数据结构（实现参考）

用 `phases` 取代现有的 `phase2`，旧字段删除。

```ts
phases?: {
  at: number;            // 进入本阶段的生命比例（第 1 阶段 1.0）
  name: [string, string]; // 阶段名（中 / 英），显示在横幅上
  minTime?: number;      // 本阶段最短时长（秒），默认 6
  speedMult?: number;    // 相对基础移速
  patterns: Pattern[];   // 本阶段的完整招式表（不是追加）
  transition?: Pattern[]; // 进入本阶段时的转场招式（转阶段 3 秒内放）
  look?: Partial<RigSpec>; // 本阶段外观变化（颜色、配件、体型），在爆发段切换
  anim?: string;          // 专属转阶段动画 id（见 BossPhaseFx），不填用通用动画
  camera?: CameraStep[];  // 本次转阶段的运镜序列（push / pull / track / pan / shake）
  arena?: ArenaChange;    // 转阶段时对场地的改变（淹没一半、缩小、长出障碍），见 ARENAS.md
  buff?: StatusApply[];
}[];
```

### 2.9 难度控制

- Boss 的**伤害数值不变**（沿用 `boss.chapterDmg`），阶段只改招式组合和节奏。
- 转阶段的转场招式统一按「可躲、伤害 ×0.8」设计，主要用来制造压力，不是用来秒人。
- 实现后跑全角色 7 章测试，对比以下几项：
  - Boss 战用时分布：目标是最快 10% 的局 ≥ 20 秒；
  - 通关率：允许各章下降不超过 5 个点；
  - 死在 Boss 战的局占比。

## 3. 各 Boss 阶段设计

招式写法：`类型(要点)`。冷却和数值在实现时按现有同类招式标定。

### 第 1 章 · 平底锅

#### 霉菌大王（mold_king）
主题：霉菌越长越多，场地被慢慢占满。

| 阶段 | 名称 | 招式 |
|---|---|---|
| Ⅰ 100–70% | 潮湿角落 | ring(14 发，慢) · summon(4 只霉菌) · slam(3 连) |
| Ⅱ 70–35% | 孢子爆发 | spiral(6 臂，带中毒) · hazard(4 块霉斑，持续 6 秒) · summon(3 只霉菌) |
| Ⅲ 35–0% | 菌落吞噬 | ring(18 发) 与 spiral 交替 · hazard(6 块，追着玩家落) · slam(落点留霉斑) |

- 转场 Ⅱ：全屏 ring(24 发) 加 4 块霉斑。
- 转场 Ⅲ：分裂出 6 只霉菌，同时在 Boss 周围落一圈霉斑。
- 动画：Ⅱ 身体鼓胀后「噗」地喷出一团孢子云，表面长出绒毛状霉斑；Ⅲ 裂开成 3 块又重新黏合，体型变大 15%，霉斑发出绿光。

#### 油烟怪厨（grease_chef）
主题：热油与油烟，激光切割场地。

| 阶段 | 名称 | 招式 |
|---|---|---|
| Ⅰ | 开火热锅 | aimed(5 发) · hazard(热油 4 块) |
| Ⅱ | 爆炒 | laser(单道慢扫) · scatter(油星 12 发) · hazard(热油 3 块) |
| Ⅲ | 满屋油烟 | laser(双道交叉) · ring(18 发) · aimed(7 发快射)，附带狂怒 |

- 转场 Ⅱ：三道激光依次扫过场地，有预警。
- 转场 Ⅲ：全屏落热油（6 块），中心留安全区。
- 动画：Ⅱ 头顶锅盖被蒸汽顶飞，冒出浓烟柱；Ⅲ 全身燃起油火，烟雾变黑并在身后拖出烟尾。

#### 蟑螂皇帝（cockroach_emperor）
主题：打不死、会再生、虫海战术。

| 阶段 | 名称 | 招式 |
|---|---|---|
| Ⅰ | 巡视领地 | charge(单冲) · summon(4 只蟑螂) |
| Ⅱ | 虫潮 | charge(两连冲) · summon(6 只蟑螂) · buff(再生 4 秒) |
| Ⅲ | 不死之身 | charge(三连冲，转向更快) · scatter(破甲 12 发) · 每 10 秒 buff(再生) |

- 转场 Ⅱ：从场地四角涌出 8 只蟑螂。
- 转场 Ⅲ：缩成虫茧（无敌 3 秒），破茧时放全屏 scatter。
- 动画：Ⅱ 翅膀张开振动，地面涌出虫影；Ⅲ 结成虫茧（茧壳用 Rig 外壳配件），茧裂开后外壳换成暗金色。

### 第 2 章 · 菜园

#### 蝗虫女皇（locust_queen）
主题：虫群遮天，从各个方向袭来。

| 阶段 | 名称 | 招式 |
|---|---|---|
| Ⅰ | 振翅 | aimed(5 发) · summon(4 只果蝇) |
| Ⅱ | 遮天蔽日 | charge(低空掠过) · summon(6 只果蝇，从屏幕边缘) · ring(16 发) |
| Ⅲ | 蝗灾 | charge 后接 ring · aimed(两轮 5 发) · summon(8 只) |

- 转场 Ⅱ：飞到场地中央，全屏 ring 两轮。
- 转场 Ⅲ：屏幕四边各刷 3 只果蝇。
- 动画：Ⅱ 升空盘旋一圈，翅膀扇起风压粒子；Ⅲ 身边环绕的小虫影越来越多，形成一圈虫群光环。

#### 腐烂南瓜王（rotten_pumpkin）
主题：笨重，落地砸场，滚动冲撞。

| 阶段 | 名称 | 招式 |
|---|---|---|
| Ⅰ | 南瓜灯 | slam(4 连) · spiral(5 臂) |
| Ⅱ | 滚动南瓜 | charge(滚动，会撞墙反弹) · summon(4 只虫子) · slam |
| Ⅲ | 南瓜炸裂 | teleport(跳到玩家附近) 后接 slam · spiral(8 臂) · summon |

- 转场 Ⅱ：高高跳起，在玩家位置砸地（大范围预警）。
- 转场 Ⅲ：南瓜裂开，全屏 scatter 喷出南瓜籽。
- 动画：Ⅱ 南瓜灯里的火从橙变紫，眼口变大；Ⅲ 南瓜表面裂开，从裂缝喷出籽和火光。

#### 鼹鼠大将（mole_general）
主题：地道战，钻地突袭。

| 阶段 | 名称 | 招式 |
|---|---|---|
| Ⅰ | 掘进 | teleport(钻地换位) · scatter(12 发) |
| Ⅱ | 地道网 | teleport 后接 slam(2 连) · summon(4 只虫子) · hazard(塌陷 3 块) |
| Ⅲ | 大将出阵 | teleport(连续 2 次) · slam(3 连) · scatter(16 发) |

- 转场 Ⅱ：钻入地下，场地上冒出 5 个预警洞口，依次塌陷。
- 转场 Ⅲ：召出 2 只精英小怪护卫，用普通怪套精英词缀，不占精英额度。
- 动画：Ⅱ 钻进地下（只剩一个土包移动），从另一处破土而出；Ⅲ 戴上将军头盔（配件），吹号角震出冲击波。

### 第 3 章 · 冰箱

#### 冰霜鼠王（frost_rat_king）
主题：寒气减速，鼠群包围。

| 阶段 | 名称 | 招式 |
|---|---|---|
| Ⅰ | 寒风 | spiral(5 臂，减速) · charge |
| Ⅱ | 鼠群 | charge · summon(4 只老鼠) · hazard(冰面 4 块) |
| Ⅲ | 极寒领域 | spiral(7 臂) · hazard(冰面跟随玩家) · charge(两连) |

- 转场 Ⅱ：全屏冰雾（所有人减速 2 秒）后接 ring。
- 转场 Ⅲ：场地边缘一圈冰刺，向中心收缩一次。
- 动画：Ⅱ 竖起尾巴吸入寒气，身体结一层霜；Ⅲ 冰冠变大，身边常驻冰晶飘落粒子。

#### 冰淇淋暴君（ice_cream_tyrant）
主题：三层冰淇淋球，每过一个阶段掉一层。

| 阶段 | 名称 | 招式 |
|---|---|---|
| Ⅰ | 三球甜筒 | ring(16 发) · summon(4 个冰块) |
| Ⅱ | 双球 | laser(单道) · ring(20 发) · summon |
| Ⅲ | 最后一球 | laser(双道) · spiral(6 臂) · 移速 ×1.4 |

- 转场 Ⅱ / Ⅲ：掉落一个冰淇淋球（变成会滚动的大型障碍物，8 秒后融化），同时放一次 ring。
- 外观随阶段变小，每阶段掉一层。
- 动画：每次转阶段最上面一个冰淇淋球「啪」地掉下滚走（变成 8 秒的滚动障碍），本体缩小一层并抖一抖；Ⅲ 只剩甜筒和最后一球，开始融化滴落。

#### 冰柜之心（freezer_heart）
主题：压缩机过载，越来越不稳定。

| 阶段 | 名称 | 招式 |
|---|---|---|
| Ⅰ | 低温运转 | scatter(12 发) · hazard(5 块) |
| Ⅱ | 过载 | teleport · scatter(16 发) · buff(屏障 4 秒) |
| Ⅲ | 临界 | ring(20 发) · hazard(全屏随机 8 块) · teleport(更频繁) |

- 转场 Ⅱ：屏障加全屏 hazard。
- 转场 Ⅲ：「过热警报」，3 秒后放一次全屏 ring 加 scatter 组合。
- 动画：Ⅱ 核心外的冰壳出现裂纹，蓝光变强；Ⅲ 冰壳崩碎，露出过热发红的压缩机核心，并伴随「过热警报」闪烁。

### 第 4 章 · 城市

#### 垃圾巨像（trash_golem）
主题：越打越散，碎片变成小怪。

| 阶段 | 名称 | 招式 |
|---|---|---|
| Ⅰ | 垃圾山 | slam(4 连) · aimed(3 发) |
| Ⅱ | 崩落 | slam · summon(2 个垃圾袋) · ring(20 发) |
| Ⅲ | 残骸风暴 | aimed(5 发快射) · ring 与 slam 交替 · summon(3 个垃圾袋) |

- 转场 Ⅱ / Ⅲ：身上掉下 3 个垃圾袋小怪，同时全屏落碎片（用 hazard 表现）。
- 动画：每次转阶段身上掉下几块垃圾（垃圾袋小怪从这里生成），体型缩小 10% 但移速加快；Ⅲ 只剩骨架状的废铁框架。

#### 毒液桶魔（toxic_barrel）
主题：毒液泄漏，场地越来越毒。

| 阶段 | 名称 | 招式 |
|---|---|---|
| Ⅰ | 渗漏 | hazard(毒池 4 块) · spiral(6 臂) |
| Ⅱ | 喷涌 | scatter(虚弱 14 发) · hazard(5 块) · summon(3 只油团) |
| Ⅲ | 决堤 | spiral(8 臂) · hazard(跟随玩家) · scatter |

## 4. 实现计划

1. **框架**：`phases` 数据结构、门槛锁血、最短时长、转阶段无敌、血条刻度、阶段横幅、「坚韧」跳字。约 1 天。
2. **通用转阶段动画**：3 秒时间轴（定格、蓄势、爆发、收势）、慢动作、镜头推近、敌弹清除、阶段常驻外观（伤痕、光环）。约 1 天。
3. **18 个 Boss 的阶段数据与专属动画**：招式只用现有类型；专属动画用 Rig 配件、换色、tween 和现有特效组合实现。约 2–3 天。
4. **测试**：
   - 单元测试：阶段数据合法、门槛递减、每阶段至少 2 个招式。
   - 全角色 7 章平衡测试：统计 Boss 战用时与通关率。
5. **需要新场地机制的转场**（本次一起做，依赖 `ARENAS.md` 的场地系统），按优先级排：冰淇淋暴君掉球、番茄酱海怪酱潮、腐烂之王缩场与残影、鼹鼠大将洞口塌陷。需要新增少量招式类型和场地变化。

## 5. 已确认

1. 门槛 70% / 35%、每阶段最短 6 秒、转阶段 3 秒作为默认值；阶段数和门槛位置按 Boss 可配置，后期再调。
2. 不做统一的最终阶段「狂怒」，由各 Boss 自己设定。
3. 腐烂之王的前代 Boss 残影：**做完整版**（多 Boss 同时存在、多条血条、击杀与成就区分本体和残影；影响见 5.1，实现后单独回调第 7 章难度）。
4. 需要新场地机制的转场本次一起做。
5. 保留慢动作与运镜，运镜按 Boss 和场景设计。

### 5.1 保留「前代 Boss 残影」的影响

| 方面 | 影响 |
|---|---|
| 代码 | 目前全局只认一个 Boss（`g.boss`）。残影要能和主 Boss 同时存在：多条血条、每个都要跑 Boss AI 和阶段逻辑；击杀、结算、成就（「击杀霉菌大王」次数）都要区分本体和残影 |
| 难度 | 第 7 章通关率目前只有 1–8%，同时面对 2 个 Boss 的弹幕会更难，需要压低残影的血量和招式频率，可能还要回调腐烂之王本身 |
| 性能 | 同屏弹幕和特效翻倍，低端手机（尤其是刚加了低内存模式的 iPhone）可能掉帧 |
| 工作量 | 约 1 天，是整个方案里最大的单项 |
| 体验 | 收益明显：真结局「群王之影」的仪式感最强，也是对前面 6 章的回顾 |

**折中方案**：残影不做成完整 Boss，而是「只会一招的影子」。每个影子只有该 Boss 最有代表性的一个招式，比如霉菌大王的螺旋、废铁巨龙的激光；血量很低，不显示独立血条，打死就消失。这样代码只多一种特殊小怪，难度和性能都可控，工作量约半天。
