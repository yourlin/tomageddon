# 第一关：怪物弹体与 Boss 形态转换

延续 [第一关美术试装](ART_CH1_PILOT.md) 的 Q 版风格。本轮补充实际战斗中使用的 11 种敌方弹体、三位 Boss 的六张进阶形态，并将形态切换接入现有三秒导演时间轴。

## 1. 弹体设计

所有弹体采用紧凑轮廓、深色外描边、明亮内沿和少量大色块，在约 18–24 像素的实际显示尺寸下仍可辨识。原图透明边距通过独立锚点和参考半径消除；显示大小按现有 `Bullet.radius` 校准，不用 PNG 的整幅尺寸充当命中范围。

| 发射来源 | 弹体 | 飞行反馈 |
|---|---|---|
| 烂苹果 | 棕红果核 | 轻快旋转 |
| 酸奶盒 | 乳白蓝纹酸奶滴 | 沿飞行方向，轻微脉动 |
| 土拨鼠 | 暖灰卵石 | 翻转旋转 |
| 霉菌大王、霉菌长老 | 青绿孢子珠 | 慢旋、轻微呼吸 |
| 油腻平底锅、怪厨Ⅰ | 琥珀油滴 | 慢旋、热感起伏 |
| 怪厨Ⅱ | 金橙火星 | 沿飞行方向，短焰尾 |
| 怪厨Ⅲ | 黑壳熔芯炭粒 | 暗壳与橙芯对比，轻旋 |
| 蟑螂将军、皇帝Ⅲ | 金棕甲壳片 | 翻转旋转 |
| 叉子骑士 | 银蓝金属尖片 | 沿飞行方向，不自旋 |
| 腐烂洋葱 | 紫色洋葱泪珠 | 慢旋、轻微脉动 |
| 蝇群之主 | 象牙绿虫卵 | 慢旋、轻微脉动 |

脉动最多为 4%，没有覆盖弹幕缝隙的长拖尾或大光晕。密集弹幕继续使用既有红色危险圈。命中碎屑采用弹体主色，碰撞与伤害依旧由原逻辑决定。

不会为原本不发射子弹的怪物凭空增加远程招式。蟑螂皇帝前两阶段仍以冲锋、召唤和增益为主，三阶段既有散射使用甲壳片。显式冰弹、蛛网等机制贴图保留原样；其他章节的发射入口不受本轮替换影响。

## 2. Boss 的持续形态与转换动作

| Boss | Ⅱ 阶段形态与动画 | Ⅲ 阶段形态与动画 |
|---|---|---|
| 霉菌大王 | 身体鼓胀，肩上长出浅绿孢子囊；吸聚粒子后喷发孢子，渐变到新形态 | 三块菌团分裂后重聚，成为三瓣融合菌落，亮绿裂纹与厚绒领持续保留 |
| 油烟怪厨 | 锅盖顶起，金属变为过热铜红，蒸汽从帽沿 / 炉口冒出 | 烟黑金属配熔橙裂隙，肩缘燃起油火，炉栅保持明亮，不用浓烟遮住眼睛和弹幕 |
| 蟑螂皇帝 | 鞘翅张开，露出两片琥珀透明翼，保留皇冠、披风与权杖 | 结茧后破壳，换成厚重暗金甲壳，金色接缝与胸甲层次持续保留 |

新形态是独立透明插画，使用同一角色的原始形象作为生成参考。每张形态单独校准脚底锚点和参考半径，避免换图时跳位；阶段体型变化继续使用既有阶段配置。

### 时间轴（游戏时间）

| 时间 | 表现 | 玩法行为 |
|---|---|---|
| 0–0.4 秒 | 定格、受击反馈、起势特效 | 沿用原有转阶段无敌与动作停止 |
| 0.4–1.8 秒 | 吸聚 / 蒸汽 / 翅振 / 结茧，身体蓄势脉动 | 原转场准备时长不变 |
| 1.8 秒 | 爆发、原有清弹与转场招式，开始切换形态 | 伤害和招式触发时机不变 |
| 1.8–2.25 秒 | 新旧形态平滑交叠 0.45 秒 | 不额外延长无敌或停手时间 |
| 2.4–3 秒 | 收势、运镜复位，新形态稳定 | 3 秒结束后切换既有招式表 |

形态交叠随实体的游戏时间推进；暂停和冻结时不会独自向前播放。已加载插画形态不再叠加旧的阶段染色，避免铜红、暗金等新设计被整张染坏；中毒、受击等状态反馈继续保留。没有形态图时回退到既有程序化染色和特效。

对象池复用时清除交叠残像，恢复基础贴图、锚点、透明度与朝向。不会让下一只 Boss 继承上一只的末阶段形态。子弹回收再使用时同样恢复默认锚点、自旋和脉动参数。

## 4. 验收

```bash
npm run check:combat-art
npm run typecheck
npm test
npm run build
# 另开终端先启动 dev（端口可替换）：
npm run dev -- --host 127.0.0.1 --port 4183
node --import tsx scripts/preview-ch1-combat.mjs http://127.0.0.1:4183/
```

浏览器验收脚本检查全部弹体来源与怪厨三阶段映射，并比较替换前后的半径、速度、寿命和伤害；对三位 Boss 各触发两次转换，检查最短阶段锁血、三秒时长、暂停中的交叠进度、六次形态稳定落地和回池恢复。结果写入 `reports/art-pilot/combat-verification.json`，截图与视频写入上面的预览目录。

本轮采用导演时间轴和形态交叠，不是逐帧精灵表；目前验证范围为桌面浏览器，移动设备的资源尺寸与显存预算仍需后续实机验收。
