# 双契合强化方案（草案 v3）

> 状态：已实现第一版（数值以代码为准：data/synergy.ts、systems/Synergy.ts、systems/Talents.ts 的 tagTraitMods）。标签、新武器、新超武见 [CHAR_WEAPONS.md](CHAR_WEAPONS.md)。

## 1. 规则

- 每名角色契合 2 个标签。
- **单契合**：武器带其中任意一个标签 → 伤害 +10%，并获得角色的契合特效（不变）。
- **双契合**：两个标签都带 → 强化的是**武器本身**，不动角色的天赋和技能。武器获得两项强化：
  1. **武器契合技**：武器按自己的攻击方式多出一个技能（第 2 节）。专属武器和主题超武有自己专门的契合技（第 4 节），替代默认的那条。
  2. **标签特性强化**：角色契合的两个标签，各把武器上对应的特性加强一档（第 3 节）。同一把武器在不同角色手里，强化的方向不同。
- 取消 v2 的「天赋进阶 / 技能进阶」，也取消临时的通用加成（伤害 +25%、攻速 +10%、暴击 +5%）。
- 武器卡片显示「★★ 双契合」，下面列出契合技和两条标签强化。

## 2. 武器契合技（按攻击方式）

| 攻击方式 | 契合技 |
|---|---|
| 直刺 | **气刃**：每第 3 次刺击，向前多射出一道穿透气刃（60% 伤害） |
| 横扫 | **回旋斩**：每第 4 次横扫变成 360° 回旋斩 |
| 子弹 | **强化弹**：每第 5 发变成大号强化弹（伤害 ×2，穿透 +2） |
| 爆炸弹 | **子母弹**：爆炸后再散出 3 颗小炸弹（各 30% 伤害） |
| 喷火 | **余烬**：每第 3 次喷射，在目标处留下 2 秒燃烧地带 |
| 光环 | **脉冲**：每 4 秒向外脉冲一次：范围 ×1.5，造成一次伤害并击退 |
| 地雷 | **余震**：爆炸后 0.5 秒原地再炸一次（50% 伤害） |
| 回旋镖 | **回程分裂**：飞到半程时分裂出 2 枚小镖（各 50% 伤害） |
| 连锁闪电 | **回流**：连锁结束时，最后一个敌人再被电一次 |

## 5. 例子

**辣椒姐（火焰＋枪械）拿辣椒火箭**：
- 单契合部分：伤害 +10%，契合特效「射程 +15%，命中多叠 1 层灼烧」；
- 契合技（爆炸弹）：子母弹，爆炸后散出 3 颗小炸弹；
- 火焰：命中多叠 1 层灼烧；
- 枪械：射程 +20%，弹速 +20%。

**同一把辣椒火箭在山葵爆破手（火焰＋爆破）手里**：契合技一样，「枪械」那条换成「爆破：爆炸范围 +20%」。

## 6. 需要注意

1. 契合技是按次数、按时间触发的武器机制，每把武器双契合时手感会有明显变化。
2. 每名角色的双契合武器只有 2–5 把，武器栏全换成双契合并不容易，强度上限可控。实现后跑快速平衡测试再调数值。
3. 第 3 节的数值是初稿，主要看方向。
