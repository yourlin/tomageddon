# 故事线：番茄酱小镇

主角固定为番茄妹，三位初始伙伴（胡萝卜骑士、辣椒姐、玉米枪手）在不同章节加入。故事和玩家当前操作的角色无关，是整个游戏的背景剧情。

## 世界观

番茄酱小镇是一座蔬果居民的小镇，镇上的番茄酱工厂供应全镇的酱料。某天夜里，腐烂开始在小镇蔓延：先是厨房，然后是菜园、冰箱、垃圾场，最后追查到番茄酱工厂。工厂被摧毁后腐烂仍未停止，真正的源头是温室地底一颗沉睡的巨大种子——腐烂之王。

## 主线

1. 一口没洗的平底锅长出霉菌，番茄妹发现了腐烂。
2. 顺着霉迹追进菜园、冰箱、垃圾场，一路收集线索。
3. 线索指向番茄酱工厂：工厂在用「腐烂配方」把小镇做成酱。
4. 工厂停了，腐烂却还在蔓延，郊外的温室开始烂掉。
5. 在温室地底找到源头：一颗在黑泥里等雨的种子。

## 角色

| 角色 | 定位 | 性格 / 口头禅 |
|---|---|---|
| 番茄妹 | 主角，番茄酱小镇的守护者 | 热心、嘴硬、有点冒失。「番茄酱小镇，我来守护！」「番茄才不是蔬菜呢」 |
| 胡萝卜骑士 | 第二章加入 | 正经的蔬菜骑士团成员，总把番茄妹当蔬菜 |
| 辣椒姐 | 第三章加入 | 火爆、爱逗人，叫番茄妹「小番茄」 |
| 玉米枪手 | 第四章加入 | 冷面的西部神枪手，垃圾场是他的地盘 |
| 老番茄藤 | 第二章（可选） | 菜园里快枯死的长辈，留下「往冷的地方去了」的线索 |
| 枯萎园丁 | 第六章 Boss | 温室的园丁，被腐烂控制，把烂掉的菜当成自己的孩子 |
| 腐土之母 | 第七章 Boss | 守护种子沉睡的腐烂之母 |
| 腐烂之王 | 真结局 Boss | 一切腐烂的源头，一颗等雨的巨大种子 |

第 1–5 章的 Boss 每局从 3 个里随机抽取，剧情里不点名，只作为「锅底升起的巨影」「工厂深处的眼睛」出现。

## 真结局（已在游戏中，`src/scenes/EndingScene.ts`）

击败腐烂之王后播放：

> 腐烂之王倒下了。
> 菜园深处的黑泥慢慢退去，露出底下湿润的土壤。
> 原来一切腐烂，都只是种子在等一场雨。
> 第二天早上，番茄酱小镇的每一块菜地都发了芽。
> 而你，是第一个看到它们的人。

## 与现有内容的对应

- 第一章章节描述「番茄妹的冒险从这里开始」与主角设定一致。
- 番茄妹的台词「番茄酱小镇，我来守护！」「番茄才不是蔬菜呢」来自 `src/data/barks.ts`。
- 各章出场怪物均为该章刷怪池中的真实怪物；第 6、7 章 Boss 为固定 Boss，第 1–5 章 Boss 不点名。
