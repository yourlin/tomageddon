# 武器套装改版方案（草案）

> 状态：设计稿，待确认后实现。

## 1. 现状与问题

- 现在的 7 个套装（厨具、锋利、蔬果、枪械、酱料、元素、爆破）按**标签**计数：持有 N 把带某标签的武器就生效。
- 一把武器常常带 2–4 个标签，随便买几把就能同时激活好几个套装。玩家不需要刻意搭配，套装也就没有存在感。
- 武器详情里的套装说明是一整行文字，看不出哪些档位已经生效。

## 2. 新规则

1. **套装由特定武器组成**：每个套装有一组指定武器，有名字和主题，比如「家常厨具：菜刀 + 平底锅 + 汤勺 + 锅铲」。
2. **按「不同的成员武器」计数**：
   - 同名武器重复持有只算 1 件；
   - 品质不限，T1–T4 都算；
   - 只算武器栏里的，仓库里的不算；
   - 超武不属于任何套装：武器进化成超武后，就不再计入原武器所在的套装。
3. **档位**：每个套装有 2 档，凑齐 2 件和凑齐全套；4 件套多一个 3 件档。
4. **一把武器最多属于 2 个套装**，大部分只属于 1 个。
5. **标签保留**：标签不再用于套装，但仍用于角色契合（契合武器、契合伤害），这部分不变。

## 3. 界面

点击武器（商店、暂停界面、仓库）时，详情里列出这把武器所属的每个套装：

```
✦ 家常厨具（2/4）
   菜刀 ✓   平底锅 ✓   汤勺   锅铲            ← 已持有的成员绿色，没有的灰色
   2 件：+2 近战伤害                         ← 已生效：绿色
   3 件：+3 近战伤害，+1 护甲                 ← 未生效：灰色
   4 件：+5 近战伤害，+3 护甲                 ← 未生效：灰色
```

- 商店里买入前预览时，会标出「买下后进入 N 件档」。
- 暂停界面的属性页加一个「套装」区，列出所有已经生效的套装。

## 5. 对平衡的影响

- 现在随便组合武器就能叠出 2–3 个套装，改版后要刻意凑同一套才有加成，**整体属性加成会下降**。
- 契合规则不变，角色流派不受影响。
- 实现后跑一轮全角色测试，看通关率的变化；如果明显变难，再统一上调套装加成。
